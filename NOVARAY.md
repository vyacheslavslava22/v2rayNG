# NovaRay

NovaRay — VPN/прокси-клиент для Android на ядре **Xray** (VLESS, Reality, VMess, Trojan,
Shadowsocks, Hysteria2, WireGuard). Основан на открытом проекте
[v2rayNG](https://github.com/2dust/v2rayNG) (лицензия GPL-3.0) и дополнен совместимостью с Happ.

## Что добавлено по сравнению с v2rayNG

| Функция | Описание |
|---|---|
| Ссылки `happ://add/...` | Открываются в NovaRay так же, как в Happ: подписка или отдельный сервер импортируются по нажатию на ссылку, из буфера обмена или по QR-коду. |
| Профили маршрутизации `happ://routing/add/...` и `happ://routing/onadd/...` | Списки «напрямую / через VPN / блокировать», DNS и Domain Strategy переносятся в правила маршрутизации NovaRay. Теги `geosite:ru` и `geosite:geolocation-ru` заменяются на `geosite:category-ru`, чтобы ядро не падало на отсутствующем теге. |
| Заголовок подписки `routing` | Если провайдер передаёт профиль маршрутизации вместе с подпиской (как для Happ), он применяется автоматически, один раз на каждое изменение. Отключается в **Меню → Группы → ⟳ «Обновить подписки» → Маршрутизация из подписки**. |
| Заголовок подписки `announce` | Сообщение от провайдера показывается в карточке подписки рядом с трафиком и сроком действия. |
| Автовыбор самого быстрого сервера | После «Тест всех серверов» выбирается сервер с наименьшей задержкой. Работает, только когда VPN выключен. Включается в **Меню → Группы → ⟳ «Обновить подписки» → Выбирать самый быстрый сервер после теста**. |
| Маршрутизация для России по умолчанию | При первом запуске на русском языке включается пресет «Россия»: российские сайты и IP идут напрямую. |
| Отдельный пакет `com.novaray.vpn` | Устанавливается рядом с v2rayNG и Happ, не конфликтует с ними. |
| Сборка в GitHub Actions | Каждый push собирает подписанные APK и публикует их в Releases. Проверка обновлений в приложении смотрит Releases вашего репозитория. |

Ссылки `happ://crypt...` зашифрованы закрытым ключом Happ. NovaRay их **не расшифровывает**
и показывает подсказку попросить у провайдера обычную ссылку на подписку. Большинство панелей
(Remnawave, Marzban, 3x-ui) выдают её в личном кабинете.

## Сборка

Сборка запускается сама при каждом push в `master`/`main` или вручную: **Actions → Build NovaRay
APK → Run workflow**. Готовые APK появятся в разделе **Releases**.

### Своя подпись (необязательно)

Без настроек APK подписывается открытым тестовым ключом `V2rayNG/ci/novaray-release.keystore`.
Для личного использования этого достаточно. Если будете раздавать приложение другим людям,
создайте свой ключ:

```sh
keytool -genkeypair -keystore my.keystore -storetype PKCS12 -alias my -keyalg RSA -keysize 4096 -validity 36500
base64 -w0 my.keystore   # вывод скопируйте в секрет APP_KEYSTORE_BASE64
```

и добавьте в **Settings → Secrets and variables → Actions** секреты `APP_KEYSTORE_BASE64`,
`APP_KEYSTORE_PASSWORD`, `APP_KEYSTORE_ALIAS`, `APP_KEY_PASSWORD`.
Приложение, подписанное другим ключом, нельзя установить поверх старого: сначала удалите старое.

## Название и иконка

- Название: строка `app_name` в `V2rayNG/app/src/main/res/values*/strings.xml`.
- Пакет: `applicationId` в `V2rayNG/app/build.gradle.kts`. Если меняете, поменяйте и
  `targetPackage` в `res/xml/shortcuts.xml`, а также `Utils.isXray()`.
- Иконка: файлы `ic_launcher*` в `V2rayNG/app/src/main/res/mipmap-*`.

## Обновление из upstream

```sh
git remote add upstream https://github.com/2dust/v2rayNG.git
git fetch upstream && git merge upstream/master
```
